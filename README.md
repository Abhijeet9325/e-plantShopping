# Paradise Nursery

A responsive plant-shop demo built with React, Vite, Redux Toolkit, and React Redux.

## Features
- Landing page with company name and a **Get Started** button
- About Us section
- Plant/product listing with categories
- Add-to-cart and quantity controls
- Shopping cart with remove, update quantity, and total price
- Responsive layout

## Run locally
1. Install Node.js (LTS).
2. In this folder run `npm install`.
3. Run `npm run dev`.
4. Open the local URL printed by Vite.
